# grove-native-delivery-k20 — brief

## Goal

Make native harness installation a complete owner-managed Grove delivery route
with Ravel 1.1, independently of the new Ravel feature. Stop automatic native
writes and make the mandate safe when guidance is missing or shipped elsewhere.

## Done when

- Startup and upgrades no longer embed or provision the broad skill corpus;
  existing owned and foreign links, pointers, snapshots and active readers are
  preserved. Explicit native installers and marketplace delivery still work.
- Installation guidance describes both owner choices and optional manual
  cleanup. Packaging and source-exact books describe the delivered change.
  Fresh native-only lifecycle launches remain usable with actual Ravel 1.1.
- The mandate names the bare skill without fixing a plugin namespace, qualifies
  first with mandatory guidance, and supplies the exact missing-skill force-stop
  rule before loading can fail. Open kinds and the existing ending contract hold.
- Focused checks, core conformance, affected installed-layout checks and Grove's
  full check pass with an explicitly selected compatible 1.1 installation.

## Decomposition

First remove the automatic writer with its build, packaging, documentation and
nonmutation checks. This leaves a useful native-only product. Then improve the
mandate and prove its ordinary and missing-guidance lifecycle behavior. Neither
requires Ravel 2. Directory delivery and dual-major admission come later.
