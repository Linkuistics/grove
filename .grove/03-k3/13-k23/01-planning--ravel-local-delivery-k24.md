# ravel-local-delivery-k24

## Goal

Grow focused working leaves for the local-source increment from the delivered
native stage and integrated Ravel directory design.

## Context

Recheck the owning repository, its instructions, Taskfile and exact preparation,
settings, worker/SDK, confinement and public CLI test seams. Read the integrated
Ravel design, not the earlier skill-catalog proposal. The parent supplies the
behavioral contract; no implementation belongs to this planning session.

## Done when

- Grow dependency-ordered leaves that leave useful public behavior after each
  handoff. Keep schema-3 migration, major identity, matching worker/SDK and usable
  launch interpretation together where inseparable. Refuse old schema 2 with its
  remedy even when sources are disabled; context/receipt schema 1 stays intact.
- Assign local capture/identity/symlinks, safe immutable publication,
  limits/deadline/cancellation, before-policy failure ordering and policy-free
  `skills resolve` acceptance to concrete work. Include disabled/malformed
  settings, direct mandatory-file reads and duplicate-name metadata that
  must not become Ravel admission rules.
- Assign actual supported confinement backends, protected-origin/alias and
  writable-overlap refusal, recovery environments, nested sessions and
  lifetime/concurrent-reader fixtures. Cover every applicable local row of the
  Ravel acceptance table, including frame bounds and controlled failures.
- Carry owning documentation, SDK/sample migration, source-exact book work and
  reusable checks with behavior. Use Ravel `typecheck`, `test:cli`, focused
  `test:session`, `check`, `smoke` and affected book/release checks as applicable.
- End with a reproducible matched temporary installation and owning commits for
  pinned delivery and Grove adoption. Preserve installed 1.1 resources/settings.
  Planning alone cannot satisfy this node's Done when; add actual work before
  retirement, and scope any earned review before dependent consumers.

## Notes

Do not activate owner skills, move packs or publish releases. Account for the
transient local-only stage explicitly, without inventing another public config
or letting required but unsupported sources launch partially.
