# grove-rhai-skill-delivery-k35

## Goal

Reconcile Grove's directory-adoption contract with the reviewed Rhai Ravel
feature contract before any dependent directory implementation or caller work.

## Context

Consume ravel-rhai-skill-delivery-k34 and its review/integration commits.
Grove's existing `docs/specs/codex-skill-provisioning.md` and
`docs/grove-skill-delivery-design-evidence.md` assign directory delivery to
Ravel 2.0/schema 3 and TypeScript SDKs. Those assignments predate Rhai main
and cannot be treated as settled feature identities. Native removal and the
route-independent mandate remain separate work.

## Done when

  cited ADR/views for the reviewed upstream contract. Separate proof of Rhai
  native compatibility from proof of directory delivery and its actual minimum
  version; both can ship together if the coordinated release design says so.
- Replace stale SDK/schema assumptions with explicit runtime, schema, assets
  and settings requirements for each supported route. Keep original launch
  endings, user-selected native delivery, open kinds and source ownership.
- Update all live common-loading stage briefs and planners with exact reviewed
  contract commits and feature identities. Reconcile summaries and consumer
  maps as well as the sections that name the obsolete assignments.
- Retain the human's release decision and named Ravel/tap handoffs. Feature
  publication and shared activation stay with rollout; any earlier native
  compatibility release needs its own explicit owner and authorization.
- Run applicable design/documentation checks and cut a focused review-design
  leaf before dependent local planning. Its body names this producer and
  challenges the upstream-to-consumer mapping and release constraints.
