# ravel-local-delivery-k23 — brief

## Goal

Deliver a useful complete local-source directory route through Ravel's public
resolution and launch boundaries, while all source packs remain in Grove.

## Done when

- Configured local sources, roots and mandatory files produce immutable retained
  resources, a directory-only descriptor and reusable loading instructions.
  Disabled delivery remains byte-identical and has no cache/network side effect.
- Public launch automatically prepares before configuration evaluation, with
  the reviewed original/prepared request fields, matching Rhai front/worker/host,
  complete frame bounds and
  exact caller/ending bytes. No per-policy helper or named-skill resolver exists.
- Local freshness, publication/concurrency, lifetime, protected origins and
  descriptor recovery pass public fixtures. Actual confined children read the
  exact external resources without writes or protected configuration access on
  supported macOS/Linux backends; failure never retries unconfined.
- Owning Ravel documentation, examples, book/source excerpts and reusable tasks
  match this delivered subset. Ravel checks and temporary installed-pair smoke
  checks pass; commits and reproducible build inputs are recorded.

## Decomposition

The first child plans this increment from current source. Grow implementation
just in time. A public `skills resolve` reader can be a useful stage only if it
actually delivers reusable complete resources and instructions; do not split a
schema or internal resolver from its only usable reader. Launch preparation,
worker interpretation and required read grants must have a green handoff.
