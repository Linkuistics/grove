# grove-dual-ravel-k27 — brief

## Goal

Make Grove explicitly compatible with the existing Ravel 1.1+ native route and
the delivered directory feature, including installed caller assets. Rhai
Ravel 2.0.0 native compatibility does not establish directory delivery.

## Done when

- Stable 1.x from 1.1.0, reviewed Rhai-native support and the directory feature's
  settled minimum release pass actual public lifecycle and standalone caller
  acceptance; unsupported/malformed/probe failures refuse
  with precise remedies and preserve canonical first-PATH selection.
- Shipped examples, typechecks, caller assets, fixtures and installed checks
  explicitly identify each supported runtime/schema. Use Rhai assets for Rhai
  releases and legacy TypeScript assets only for 1.x. No owner policy is overwritten.
- Local, pinned and warmed offline directory launches preserve mandate/endings,
  mandatory order and resource access. Native-only lifecycle needs no sources;
  confined native access is measured separately without a directory-grant bypass.
- Caller specs/ADRs/views, glossary, source-exact books and release inputs agree
  with behavior. Full Grove checks and affected archive/formula/floor checks pass
  with explicit matching independent Ravel builds and homes.

## Decomposition

The planner consumes delivered Ravel builds before cutting caller/version and
installed-distribution increments. A version predicate change alone cannot
establish compatibility or justify publication.
