still exist: `choice::prepare`, `rhai_request`, `engine::request_map`,

`FRONT_FRAME_BYTES`. The four examples still export `SCHEMA_VERSION` 3. The

`task test:native-linux` runs the Linux image. Ravel has no `CLAUDE.md` or
`AGENTS.md`. Its `.grove/` tree belongs to the paused workstream.

**The first increment is schema 4 with delivery disabled.** That build is the
native-only route on 2.0, which Grove's dual-Ravel stage proves separately. It
keeps the request transition, the schema-3 refusal, both request halves, the
routing-notice `skills: null`, the frame bound and its check together. The
frame bound already counts the prepared prompt and the descriptor, so its three
tests do not need enabled delivery. Every schema-3 example, fixture and book
page moves with it.

**The first enabled reader is `ravel skills resolve`.** It reads the settings,
captures local sources, publishes snapshots and the descriptor, and prints the
preamble. An independent harness can use that output, so it delivers complete
resources and instructions. The settings object, repeated-member detection,
local capture, symlink rules, the protected-origin boundary of sources and the
temporary Git refusal land with it. None of them has another reader.

**Launch preparation follows the resolver directly.** Hardening leaves then
prove each failure at both public seams, `skills resolve` and `start-session`.
That order gives the useful end-to-end route early and tests the shared
resolver once for both readers.

**A confined launch with delivery enabled refuses until the confinement leaf.**
The launch leaf cannot grant the snapshot reads under `--confine`. It therefore
refuses that combination as `skill_access_unavailable`, stage `skills`, exit 3,
before the worker. That code already means "a grant that the backend cannot
give", so the refusal invents no public configuration and launches nothing
partially. The confinement leaf replaces it with the real grants. Unconfined
launches and disabled delivery are unaffected.

**Rows outside this stage.** Exact Git, offline reuse, the Git half of Git LFS,
missing revisions and transport cancellation belong to
`ravel-pinned-delivery-k25`. Delegate authority and agent recovery after
compaction need actual harnesses, so they belong to
`common-loading-acceptance-k29`. The completion of the unfinished Rhai book
work belongs to rollout, as `docs/specs/coordinated-release.md` step 2 states.
This stage moves schema-3 pages and documents only what it delivers.

**No planning review.** Each leaf cites the reviewed contract `822c0ed2` and its
acceptance rows directly, so an implementer checks the plan against the
contract at entry. Producers cut any earned `review-impl` lazily. A review
must precede the handoff leaf, so its producer inserts it before that leaf.
