## Decisions (running log)

**Base.** On 2026-11-03 this checkout was at `5c9c21e58bde`, the commit of
ravel-local-sources-k90. The Ravel bookmark `skill-directory-delivery` was at
`4f831feb4d0f`, above the build commit `78332fcc367d`. Ravel `main` was
`24a545236185`.

**The two builds.** The 1.1 build is the Homebrew keg
`/opt/homebrew/Cellar/ravel/1.1.0`, with a front and a Bun worker. That keg is
also the ending executable of the live driver, so no leaf changes it. The 2.0
build is the directory build of k90. It installs one executable and no
`libexec/ravel` worker, and it reports `ravel 1.1.0`. Its delivery-disabled
launches are the native route on 2.0.

**The first increment is the test seam.** Every installed-Ravel test writes a
TypeScript `policy.ts` with schema 2, and `testing/ravel.rs` copies the 1.1
front and worker. No Grove check can run against the 2.0 build until the
support selects the runtime explicitly. The version output cannot select it.
That leaf also proves the native route on 2.0 for the lifecycle and standalone
callers with fixture configurations. It is useful alone, and the asset and
directory leaves build on it.

**The Rhai port is two increments.** The case table, the sample and the static
example form one increment: an owner can use the native route on 2.0 without
creator-aware review. The review adapter, the review examples and the
provenance wrapper form the second. Both leave the TypeScript set and its
installed paths unchanged.

**Asset layout.** Each Rhai asset sits beside its TypeScript counterpart at the
same relative path, with the extension `.rhai`. Grove ships its own copy of
Ravel's static example, because Ravel 2.0.0 embeds no module. The Ravel
migration table names a copy imported by its path.

The asset leaf records this
in the assets README and the caller specification. It can depart with a
recorded reason. This choice needs no design leaf. It follows the upstream
migration rule and changes no Grove interface.

**Admission follows the assets.** The delivery specification admits 2.x only
after the native route on 2.0 passes caller acceptance with the Rhai assets.
The admission leaf therefore comes after both asset leaves. It owns the owner
guidance for the native route on 2.0, the caller specifications, the glossary
and the source-exact books that the resolver change affects.

**The directory route is two increments.** The lifecycle leaf proves local
sources, a plain Git checkout at a commit, a missing checkout and a launch
without a network. It also proves settings isolation and resource lifetime. It then
advertises the directory route. The confinement leaf proves the confined
standalone route and the native unreadable case separately.

**Installed distribution is two increments.** The archive leaf owns the
archive layout, the formula, its caveats and the installed smoke. The target
leaf owns the pinned independent inputs, the target and floor smoke and the
legacy-driver continuity. A final handoff leaf runs the full checks with each
explicit build and records the stage for k29 and k6.

**No design leaf.** The delivery specification, its runtime parity and the
coordinated release settle every public choice that these leaves make. The
runtime variable of the test support, the case-table format and the network
guard are internal test wiring, which the specification leaves to
implementation.

**Coverage.** Each Done when item of this leaf maps to a cut leaf. The node
brief's "Builds and homes" section holds the exact owning commits and the
build and HOME recipes. The keg digest `c52f990b2059…` matched the recorded
value on 2026-11-03. grove-dual-ravel-handoff-k102 records the publication
order for k29 and k6.

**Review.** No review leaf. Each new leaf restates a reviewed contract, and
k102 checks the node's Done when against recorded results. This leaf spent no
in-session reviewer.
