# repository-moves-k11

## Goal

Turn the proven research-pack pattern into small, independently verifiable
moves for every remaining destination and writing project.

## Context

Consume external-research-pack-k4's durable contract and acceptance evidence.
Inventory the actual remaining source membership and owning repositories now;
the root brief governs placement and exclusions.

## Done when

- Reconcile all remaining skill/resource/hook ownership with the agreed
  destinations. Any ambiguous membership gets a precise design question
  before its move, without changing the agreed domain boundaries.
- Grow separate working subtrees for independent domain, personal,
  TestAnyware, marketplace and writing-project moves. Order shared resource
  dependencies and source-index changes so each handoff works.
- Each subtree names its preservation evidence, affected references, own
  checks and aggregate conformance contribution. Project relocation includes
  before/after content, edits, history and workspace-registration checks.
- The created work covers every remaining root obligation; the final rollout
  consumes concrete results rather than inheriting unspecified migration work.

## Notes

Avoid identical speculative implementation recipes for every pack. Cut current
detail lazily, retaining each precise destination obligation as live work.
Owner configuration changes belong with the move that needs them and follow
the maintained machine contract.
