# owner-switch-simplification-k263

**Integrates:** owner-switch-simplification-k261

## Goal

Triage the review of the simplified owner switch design and integrate the
actionable findings before owner-switch-simplification-k262 plans from it.

## Context

- Read the findings from the committed review
  owner-switch-simplification-k261. Its durable report is the section "Owner
  switch simplification review" of `docs/owner-skill-delivery-evidence.md`.
  The task file of that review holds its running decisions.
- The producer is owner-switch-simplification-k260. Its task file holds the
  human's words and the four chosen simplifications.
  `docs/specs/owner-skill-delivery.md` owns the switch contract.
- The section "Single-owner switch design" of the evidence document is in a
  pending region of the controlled-English conversion. Convert it before an
  edit changes it.

## Done when

- Each finding has a recorded disposition supported by the source and the
  owning contract.
- The design, the coordinated recovery rows, the decision records and the
  diagrams are current for each accepted finding. Search the claim, not a
  file list.
- The parent brief's consequence tables give k262 each changed consequence.

## Notes

This integration changes the design only. The real HOME, launchd and the
process table stay read only. The four simplifications are the human's
choice. A finding that would reverse one of them goes to the human with a
recommendation.
