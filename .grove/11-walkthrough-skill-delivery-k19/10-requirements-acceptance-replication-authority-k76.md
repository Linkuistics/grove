# acceptance-replication-authority-k76

## Goal

Decide whether and under what evidential rule a post-failure replication of the
unchanged historical walkthrough-skill experiment may discharge the parent
behavioral acceptance claim.

## Context

- Clause-to-evidence trace and recommendation:
  `acceptance-contract-reconciliation-k75`.
- Parent contract: `walkthrough-skill-delivery-k19` and the root brief.
- Negative historical verdict:
  `docs/evaluations/writing-code-walkthroughs/README.md`.
- Frozen instrument:
  `docs/evaluations/writing-code-walkthroughs/baseline/rubric.md`.
- No evaluated treatment or control context may run before this decision and
  the scheduled review-planning chain are settled.

## Done when

- Explicitly choose one contract:
  1. authorize one separately frozen exact-instrument final-digest replication
     to discharge the behavioral clause independently if it meets the unchanged
     rubric, while preserving the original failed result as contrary historical
     evidence;
  2. retain the current strict contract, record behavioral acceptance as failed,
     and prohibit recovery execution until later skill-revision/evaluation work
     is authorized; or
  3. amend the parent acceptance clause so a new requirement-derived paired
     instrument may replace the unchanged-rubric requirement.
- State whether the decision is an amendment to the parent brief and edit the
  durable acceptance wording when it is. Do not encode the choice only in this
  task file.
- If replication is authorized, define exactly whether it independently
  discharges, supersedes, combines with, or merely corroborates the original
  failed enabled arm. Silence is not authority to choose the favorable result.
- Confirm that the historical records remain the sole pre-skill baseline and
  that recovery no-skill runs are contemporaneous comparators only.
- Confirm which transfer contract applies: exact rerun of the already frozen
  fzf probe, a newly selected supplemental probe, or an explicit requirements
  amendment allowing a new probe to discharge the clause.
- Confirm that every new requirement-derived row or protocol rule remains
  supplemental unless the parent acceptance wording is explicitly changed.
- Reshape or externalize any downstream work the choice makes necessary before
  retiring. If the strict contract is retained, no live-model campaign leaf may
  proceed merely because it is already present.

## Notes

Recommended: authorize one exact-instrument replication as an explicitly named
requirements amendment. This is the smallest change that can test the final
deployed bytes without relabelling a post-skill control as a pre-skill baseline
or pretending the original failed arm never existed. It still requires the
report to present both results and to limit any acceptance claim to the precise
authority granted here.
