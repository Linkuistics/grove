# 11.2-[25]-read-verbs

**Kind:** work

## Goal

Re-express the read verbs against the directory tree (ADR-0035), on top of 11.1's
id model: `pick`, `brief-chain`, `resolve`.

## Done when

- `pick` — recursive DFS over `.grove/` in per-level numeric order, returning the
  first live leaf (skip `BRIEF.md`, skip `DONE` leaves, descend nodes in order).
  Empty stdout + stderr diagnostic when no live leaves (unchanged contract).
- `brief-chain` — walk the leaf's parent directories root→leaf, emitting each
  `BRIEF.md` found (root `.grove/BRIEF.md` first). A level with no brief is
  skipped silently.
- `resolve <ref>` — find the current path by `[key]`/bare key (searching live AND
  `DONE`, across the dir tree) or by slug (0/1/many with key-listing on
  ambiguity). Pick-style: not-found/ambiguous → stderr, exit 0.

## Notes

- Semantics are ADR-0033's, re-homed onto dirs — keep behaviour identical so the
  loop and prompts are unaffected; only the walk changes (flat scan → recursion).
