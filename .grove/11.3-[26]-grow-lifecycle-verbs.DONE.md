# 11.3-[26]-grow-lifecycle-verbs

**Kind:** work

## Goal

Re-express the grow + lifecycle verbs against the directory tree (ADR-0035):
`leaf-add`, `leaf-insert`, `leaf-decompose`, `leaf-retire`, `root-init`.

## Done when

- `leaf-add <parent-id> <slug>` — create a leaf file at the parent dir's next
  gapless `NN`, fresh `[key]`.
- `leaf-insert <target-id> <slug>` — insert at `NN`, shifting the occupant + later
  siblings up by one via **`git mv` of whole directories** (subtree + child names
  + keys ride along untouched — the cascade collapse, ADR-0035). Rewrite only the
  shifted siblings' own `NN`; surface positional cross-refs as a lint.
- `leaf-decompose <leaf> <first-child-slug>` — `git mv` the leaf *file* into a node
  *directory* `NN-<slug>-[<key>]/` (**key preserved**) with a `BRIEF.md` (seeded
  from the leaf body) + an atomic first child.
- `leaf-retire <leaf>` — add the `DONE` infix in place (`NN-<slug>-[k].md` →
  `NN-DONE-<slug>-[k].md`); refuse a brief / already-done leaf.
- `root-init [<slug>]` — `.grove/BRIEF.md` + first leaf `01-<slug>-[1].md`.
- All working-tree-only (no commit); unit + integration tested.

## Notes

- The insert renumber is now O(siblings at one level), not O(subtree) — verify a
  fixture where inserting a node shifts a sibling node and its grandchildren stay
  byte-identical except their ancestor dir name.
