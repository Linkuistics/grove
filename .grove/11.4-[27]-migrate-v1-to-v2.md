# 11.4-[27]-migrate-v1-to-v2

**Kind:** work

## Goal

The migration that flips a tree to v2-directories (ADR-0035), reusing ADR-0034's
migrate-on-adoption mechanism. Fixture-tested **hard** before it touches a real
tree; one reviewable, revertable commit; idempotent on an already-v2 tree.

## Done when

- Converts **v1-flat → v2-dirs**: each `NN.MM-[k]-slug[.DONE]` flat file becomes
  its dir-nested `NN-…/MM-[DONE-]slug-[k].md`, node briefs become
  `NN-slug-[k]/BRIEF.md`, the root brief stays `.grove/BRIEF.md`. Order, done-ness,
  brief-chain, and **keys** all preserved.
- Also converts an un-opened **old `NNN-slug/` tree → v2 directly** (a grove that
  never opened since 070/040). After this, the reader is **v2-only** — the v1-flat
  and old-`NNN` readers shrink to this migration's one-time inputs.
- `detect()` distinguishes v2 / v1-flat / old-`NNN` / empty; `grove do` runs it on
  adoption (idempotent no-op on v2). `grove migrate` stays as the explicit verb.
- Golden fixture pinning this grove's exact tree (incl. the partially-retired
  node 11 and node 07).

## Notes

- Mirror `migrate.rs`'s structure (plan = pure, execute = git mv + rewrites). The
  v1→v2 plan must compute *per-level* positions from the flat dotted ones.
