# 11.5-[28]-prose-and-commit-convention

**Kind:** work

## Goal

Rewrite the methodology prose to the v2-directory scheme and add the
commit/reference naming instruction (ADR-0035 §5).

## Done when

- `content/` (SKILL.md, BRIEF/TASK/ADR/CONTEXT format guides, prompts) describes
  the **directory** model: node = dir with `BRIEF.md` + numbered children, leaf
  `NN-[DONE-]slug-[key].md`, root `.grove/BRIEF.md`, per-level 2-digit positions,
  `[key]` stable id, `DONE` infix. No stale flat/dotted-`.DONE`-suffix language.
- **Commit-naming instruction** added to SKILL.md (and reflected in the prompts):
  *reference a work item by `<slug>-[<key>]`, never by its position or directory
  path* (positions/paths are mutable; the handle is stable). Replaces the
  inconsistent `070/030`-style path references.
- `CONTEXT.md` glossary updated: the resolved terms (position vs. permanent key /
  stable id, node directory, work-item title).

## Notes

- The global skill is binary-embedded + re-extracted on launch (ADR-0034), so this
  prose ships with the v2 binary (11.6) — no separate sync. Project-local mirrors
  are already being removed (070/050).
