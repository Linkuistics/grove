# 11.6-[34]-rationalise-adrs-and-docs

**Kind:** work

## Goal

Rationalise the project's decision/documentation corpus so the v2 release ships a
**coherent, non-contradictory** document set. A dedicated pre-release pass over
the ADRs (and the other docs) — sequenced **before** `install-and-reflip-[29]` so
the released binary carries clean docs.

## Context

- **35 ADRs** have accumulated across several reversed or superseded subsystems:
  the TUI / trellis / rmux tower (`0013`–`0030`, much of it already swept at the
  070-teardown), the inbox / grove-meta model (`0002`–`0005`), install /
  materialise (`0001`, `0008`), and the live refactor-to-archon set (`0031`–`0035`).
  Many are now historical or superseded but still read as authoritative.
- Other docs in scope: `CONTEXT.md` (glossary), `docs/specs/`, `docs/research/`,
  `docs/prd/`, and `README`.
- This grove (refactor-to-archon) is nearly complete; this is the pre-release
  doc cleanup. The worked precedent is the 070-teardown, which swept the
  `0013`–`0028` ADR tower.

## Done when

- Every ADR carries an accurate **Status** (accepted / superseded-by-NNNN /
  deprecated / historical), and superseded ones point at their successor — so the
  *live* set (what still governs the current code) is identifiable at a glance.
- Stale or contradictory prose across `docs/` and `CONTEXT.md` is reconciled or
  marked historical: no doc asserts something the refactor reversed (no TUI /
  inbox / install-machinery claims; the v2 directory scheme and the
  binary-embedded global skill described correctly).
- `README` / top-level docs reflect the shipped reality (`brew install`, the
  binary-provisioned global skill, the self-driving loop, the v2 scheme).
- The keep / supersede / merge / archive vs. mark-in-place policy is **decided and
  applied consistently** across the corpus.

## Notes

- A **work** task, but it carries real judgment (keep / supersede / merge /
  delete). If a genuinely contentious call surfaces (e.g. delete vs. retain a
  historical ADR, or renumber the set), **confirm it** rather than deciding
  unilaterally; grill if several such calls interdepend.
- Scope guard: rationalise the *existing* corpus — don't author new ADRs unless
  the rationalisation itself is a decision worth recording.
- Sequenced by the operator (2026-06-22) ahead of `install-and-reflip-[29]`.
