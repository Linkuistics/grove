## Decisions (running log)

Use the approved item-status design and existing public Viewer/real-launch seam.
The runtime summary is independent of tree acceptance: current same-tree rows
use their current handle; missing items use the launch handle; exceptional tree
relations reserve their qualifier before truncating the slug. Accepted previous
trees select NEXT without exclusion; accepted same-tree item absence still
selects the remaining candidates. Failed tree acceptance suppresses attachments
and NEXT, while preserving fresh runtime evidence.

Implementation plan: extend real-launch application tests for absence,
replacement and stale tree summaries and observe their failures; implement the
summary/forecast change; add remaining launch-transition and saved-state controls;

frozen-input principal gate; commission the required protocol review, retire k44
and close k27, then seal with jj and signal. No new framework API or protocol
is needed, and no in-session review is commissioned alongside the tree review.
