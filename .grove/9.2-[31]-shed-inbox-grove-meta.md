# 9.2-[31]-shed-inbox-grove-meta

**Kind:** work

## Goal

Delete the **inbox / `grove-meta` branch** subsystem in full (ADR-0002–0005 + 0012).
The seeds were re-homed in 9.1, so this is a clean deletion.

## Done when

- **Code deleted:** `src/inboxes.rs`, `src/meta.rs`, `tests/inboxes.rs`,
  `tests/meta.rs`, their `pub mod` lines in `lib.rs`.
- **`grove` surface (`cli.rs`):** drop `Command::Inbox` + `Command::Meta` and their
  dispatch arms; drop `InboxArgs`/`InboxCommand`, all `Meta*` arg structs, and the
  inbox arg structs (`InboxAddArgs`/`InboxDrainArgs`/`InboxEditArgs`/
  `InboxRemoveArgs`/`InboxShowArgs`).
- **`grove-llm` surface (`llm_cli.rs`):** drop `InboxAdd`/`InboxDrain`/`InboxEdit`/
  `InboxRemove` variants + their `cmd_*` fns + the `inboxes` import + the
  `read_body` helper (only the inbox verbs used it — confirm no other caller).
- **SKILL.md (`content/SKILL.md`) — methodology stays, machinery goes:** remove the
  **Drain** bootstrap step from the loop; remove the "Inboxes and capture" section;
  remove the `grove-meta` branch artifact row from the Artifacts table; remove
  finish-cycle **step 4** (inbox cleanup) and renumber the remaining steps + their
  back-references (the prose has several "steps 3, 5 and 6" call-outs); drop the
  `--for`/`inbox-drain` mentions from Bootstrap. Check `content/prompts/*` and the
  other `content/*FORMAT*.md` for inbox/Drain references too.
- **Glossary (`content/CONTEXT.md` and the worktree `CONTEXT.md`):** remove the
  **Inbox**, **Seed**, **Drain**, **grove-meta branch** entries; drop the Drain
  clause from **Bootstrap**; drop the inbox step from **Complete finish cycle**;
  remove the canonical Inbox/Seed/Drain example callout. (NB: the project's own
  `CONTEXT.md` is the canonical-example carrier — fix both copies if they diverge.)
- **ADRs marked Superseded** (status line → `superseded by ADR-0031`, one-line
  why): 0002, 0003, 0004, 0005, 0012. **Leave ADR-0006 accepted** (binary split
  survives, affirmed by 070).
- **`grove-meta` branch + worktree removed:** `git -C <repo> worktree remove
  <repo>/.grove-meta` then `git -C <repo> branch -D grove-meta`. Confirm 9.1 left no
  pending seeds. Drop the `.grove-meta` entry from `Cargo.toml`'s `exclude` if it
  no longer needs excluding (the `:`-in-filename packaging note).
- `cargo build` + `cargo test` green; `grove --help` / `grove-llm --help` show no
  inbox/meta verbs.

## Notes

- `grove install` *also* references `inboxes`/`meta` (it calls `meta init`). That
  call is removed here or in 9.3 — coordinate: simplest is for 9.3 (which deletes
  `install.rs`) to drop the whole module, so here just ensure no *surviving* module
  imports `inboxes`/`meta`. If 9.2 runs first, stub/remove the `meta init` call in
  `install.rs` so the build stays green until 9.3 deletes it.
- Do **not** touch `harness_stamp.rs` (`.grove-stamps/<name>` is harness binding,
  not inbox).
