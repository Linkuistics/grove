# grove

The grove skill now lives in its own repository: <https://github.com/Linkuistics/grove>.

Install via Homebrew:

```
brew tap Linkuistics/taps
brew install grove
```

Materialise into a project:

```
grove install [<repo>]
```

See `grove --help` for the full command surface, or the new repo's `README.md`
for documentation. The methodology itself (BRIEF/CONTEXT/ADR formats, the
grilling procedure, the task-tree loop) is unchanged — only the distribution
mechanism moved.
