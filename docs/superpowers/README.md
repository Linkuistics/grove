# Superpowers-workflow artifacts

A plan and its approved design spec from one past workstream — the 2026-07-18 Codex/Pi harness switch, shipped in grove v12.0.0. They follow the `superpowers:writing-plans` / `superpowers:executing-plans` shape rather than grove's, which is why they sit here and not in `docs/specs/`.

**Read them for provenance, not for current state.** The plan's checkboxes record what was done in July 2026 and nothing tracks them now; the spec already carries its own note that its paths predate the skills merge ([`../adr/skills-monorepo.md`](../adr/skills-monorepo.md)) and are kept as written. What the switch settled has since been restated as current-state in the ADR set — [`../adr/model-per-task-kind.md`](../adr/model-per-task-kind.md) is the one to read, not the spec.

**One live commitment, unlike everything else here.** The spec's status line records a model trial running 2026-07-18 to ~2026-08-18. That is the only forward-dated claim in this directory; when it lapses, edit the ADR set to say what the trial concluded and this directory becomes purely historical.
