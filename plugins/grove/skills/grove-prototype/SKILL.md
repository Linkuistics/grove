# prototype

**Load the `grove` skill now** — on Claude Code, where plugin skills are
namespaced, that is `grove:grove`. It is the shared spine and holds everything
this kind does not own: the constraints, the bootstrap, and the execute,
decompose, retire and commit procedures. What follows is `prototype`'s, and is
stated nowhere else.

**prototype** (HITL) — a cheap, deliberately throwaway artifact built to react
to, not to ship. The reaction it provokes *is* the deliverable, so the code's
survival is not the point and **polish is a defect**: effort spent making it
presentable is effort not spent getting it in front of the human whose reaction
the leaf exists to collect.
