# utc-changelog-k1

## Goal

Add an entry to `CHANGELOG.md` for this change: the repository now writes
every timestamp in UTC, in ISO 8601 form, such as `2026-11-03T04:05:06Z`.

## Guidance

Load the skill `changelog-conventions` before you write the entry.

## Done when

- `CHANGELOG.md` holds one entry for the change.
