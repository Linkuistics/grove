# stamp-cli-k1

## Goal

Design the command-line interface of a tool `stamp`. The tool writes the
current UTC time in ISO 8601 form, such as `2026-11-03T04:05:06Z`, to a file
or to standard output. Write the design to `docs/stamp-cli.md`. Do not
implement the tool.

## Done when

- `docs/stamp-cli.md` states the usage line, the flags, the output, the exit
  codes and the error messages of `stamp`.
