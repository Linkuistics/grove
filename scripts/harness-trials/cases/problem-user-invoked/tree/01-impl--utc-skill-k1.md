# utc-skill-k1

## Goal

Add the skill file `skills/utc-timestamps/SKILL.md` to this repository. The
skill tells an agent to write every timestamp in UTC, in ISO 8601 form, such
as `2026-11-03T04:05:06Z`.

## Done when

- The file has a `name` and a `description` in its front matter, and a
  short body.
